# dyad-crystal-items

Shared item-envelope archetypes for every Dyad crystal item (weapon + armor,
tiers 1 to 6). Generated by `tools/dyad-crystals/generate_dyad_specs.py`; do not
hand-edit `index.yml`.

## Definitions

Three inheritance levels, all resolved at registration:

- `DyadCrystalCommon` carries the ~26 leaves that are constant across every Dyad
  crystal item (combat type, bind/stack/store flags, gamble type, drop assets).
- `DyadWeaponCommon` / `DyadArmorCommon` extend it with the per-slot `category`,
  `requiredEquipmentType`, and the constant `strings.toolTip`.
- `Dyad{Slot}{Tier}Base` (12 exported bases: `DyadWeaponRhombBase` through
  `DyadArmorCruxBase`) bake the tier economics: `name`, `gambleItemGrade`,
  `level`, `requiredLevel`, `buyPrice`, `sellPrice`, `defaultValue`.

## Consumers

The 12 `specs/patches/002/11-dyad-crystals-{weapon,armor}-t{1..6}.yaml` specs.
Each imports this package and its per-item entries `$extends` the matching
`Dyad{Slot}{Tier}Base`, supplying only `id`, `name`, `linkCustomizingId`,
`conversionSmallGroup`, `icon`, and the per-item `strings.name`.

## Regeneration

`python tools/dyad-crystals/generate_dyad_specs.py` rewrites this package and the
12 consumer specs together from a single source of truth (the `TIERS`,
`WEAPON_FAMILIES`, `ARMOR_FAMILIES` tables), so the bases and the specs can never
drift apart. Gate any change with `dsl expand` deep-compare.
