Restore Island of Dawn to its classic state on the v92 server, with the old client v17.11 as the north star and v31 filling gaps only where v17 lacks data (server-side families). ## Strategy (settled)

- **Source precedence:** v17.11 client authoritative for existence, quests (logic AND rewards), geometry, strings. v31 server supplies encoding-level gap-fill only, always keyed to a v17-rostered entity. Confirmed necessary: v31 is the same rework era as v92 (identical 40-quest sentinel-disabled set, re-tuned rewards); it must NOT drive quest content.
- **Reconciliation, not layering:** every scoped entity gets exactly one verdict (MATCH / RESTORE / REMOVE / GAPFILL / DECISION) by its natural key. Specs define complete target state per scoped keyspace including explicit deletes. This prevents the duplication that sank the previous v31+v17 layering attempt.
- **Keying is proven safe:** all 218 NPC templates and all 63 quests carry identical ids across v17/v31/v92, zero reuse (id-alignment artifacts).
- **Provenance:** every target row records v17 | v31-gapfill | v92-keep | patch-000.
- **Apply model:** `migrate --patch 001` with `--source-ref` against baseline HEAD 9c7163fe; idempotent upserts; fail-fast batch. Post-apply gate: classifier re-run expecting zero RESTORE/REMOVE, `audit_quests` showing exactly the target quest set, in-game validation, then baseline-lane commit.
