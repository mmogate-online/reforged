# v17 -> v31 Territory Correlation

Each v17 client territory (fence ring, no server id) is matched 1:1 to a v31 server territory by fence-vertex geometry: exact rounded vertex-set match first, then a near-match by symmetric mean nearest-vertex distance (<= 400), each v31 territory claimed at most once.

**Read the scope column.** v17 and v31 share group ids in this dataset, so a same-group match (scope `group`: all exacts plus near-group) is an identity correspondence and is high confidence. A cross-group near match (scope `hz`) is a spatial coincidence: the v17 territory sits within the tolerance of a surviving v31 territory that belongs to a *different* group, so it is NOT the same territory. Cross-group near matches come almost entirely from the v17-only (deleted) mob-camp groups and should be read as losses that happen to overlap a surviving neighbour, not restorable correspondences. The `Near (cross-group)` column isolates them.
